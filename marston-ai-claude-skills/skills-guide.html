Skills are the cheat code. This is the loadout.

A Claude Skill is a small folder — usually just a SKILL.md file with instructions, plus optional scripts and resources — that Claude loads on demand to become an instant expert at a specific job: building videos, writing production React, auditing security, cutting your token bill. You don't prompt-engineer it every time. You install it once, and Claude just knows.

This isn't a "how to build skills" doc. It's a curated stash of the best skills that already exist — proven on GitHub, gone viral on X, recommended on Reddit — with full credit to the people who made them. Steal freely. Ship faster.

How to install any skill in this guide
  1. Grab the skill folder from its repo (the link is on every card).
  2. Drop it into ~/.claude/skills/ for global use, or .claude/skills/ inside a project. On Claude.ai, upload the skill in Settings → Capabilities → Skills.
  3. Restart Claude Code (or refresh). It auto-detects the skill from the description.
  4. Trigger it naturally — "make me a video", "grill me on this plan" — or run its slash command. Claude loads it only when it's relevant, so your context stays clean.
