Starter pack: if you only install five
What's inside
Don't build skills.
Install them.

A Claude Skill is a small folder — usually just a SKILL.md file with instructions, plus optional scripts and resources — that Claude loads on demand to become an instant expert at a specific job: building videos, writing production React, auditing security, cutting your token bill. You don't prompt-engineer it every time. You install it once, and Claude just knows.

Most people approach skills backwards: they open the skill-creator and try to build everything from scratch. That's a waste. Anthropic ships 17 official skills for free, and the community has published 1,500+ more. The best ones already exist — proven on GitHub, gone viral on X, recommended on Reddit. This directory is the curated shortlist, with full credit and a link to every author. Steal freely. Ship faster.

How to install any skill in this guide
  1. Claude.ai (web): Settings → Capabilities → Skills → Upload custom skill, then drag in the skill folder. (Pro/Team plan; Anthropic's official skills are pre-installed for free.)
  2. Claude Code (plugin): /plugin marketplace add <org>/<repo> then /plugin install <skill>.
  3. Claude Code (npx): npx skills add <org>/<repo> — works for any public GitHub repo.
  4. Manual: clone the repo and copy the folder into ~/.claude/skills/ (global) or .claude/skills/ (per-project).

Three rules before you go wild. (1) Install 5 to start, not 50 — each skill adds overhead to every session; begin with the ones that match this week's work. (2) Read the SKILL.md before installing — some run scripts or auto-update from upstream. (3) Prefer official + named-author skills with real star counts; that's the cheapest reliability signal.
